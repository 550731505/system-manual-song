# 交付前验收清单

逐条打勾，任一条不过就不要交付。

## 数据

- [ ] `config.json` 的 `id` 与目录名一致，`order`、`updated` 已填
- [ ] `manuals[].file` 与 `manual/` 下实际文件名完全一致（含空格、`-`、中文）
- [ ] `roles[].dir` 与 `screenshots/` 下子目录名一致
- [ ] 每条 `entries[].shots` 里的序号都能在 `screenshots/<dir>/<dir>_NN.jpg` 找到文件
- [ ] `shots` 里的图与 `answer`/`steps` 讲的是同一件事（抽样 5 条点开比对）
- [ ] 每条 `entries` 都有 `source`（章节），`id` 不重复
- [ ] 手册没写的政策/时限/费用没有出现在 `answer` 里，而是进了 `gaps`
- [ ] 手册笔误（代办/待办、经济机构/经纪机构）已按界面菜名统一

## 审核表

- [ ] `python tools/build_review_xlsx.py <sys>` 已执行，xlsx 在系统目录下
- [ ] 审核表条数 = `kb.json` 的 entries / gaps 条数
- [ ] 「怎么用」页里的系统名、地址 `#/<sys>` 正确

## 页面（构建产物实测）

- [ ] `yarn build` 通过
- [ ] `node .opencode/skills/manual-from-word/scripts/smoke_test.js <sys>` 全部 OK
- [ ] 首页卡片出现该系统，名称与 `config.json` 一致
- [ ] 多角色系统：三个角色都能切，模块计数不为 0
- [ ] 单角色系统：不出现角色切换条
- [ ] 检索一个常见问题（如“怎么登录”）能命中
- [ ] 检索一个手册没写的问题（如“收费标准”）→ 提示「手册暂未覆盖」并带出缺口
- [ ] 缩略图点开能放大、左右能翻页、Esc 能关
- [ ] `?embed=1` 时页头隐藏（业务系统内嵌用）

## 智能问答（`?mode=qa`）

- [ ] 进入问答模式有欢迎语（含角色名与收录条数）和快捷提问
- [ ] 点快捷提问能直接出答案卡（含步骤、依据、截图）
- [ ] 输入一句话问题能给出答案；答案里的截图能点开
- [ ] 短句追问（如「那这个呢」）仍能答，不会掉到未覆盖
- [ ] 带新名词的追问（如「那监管账户怎么审」）能切换到新问题，不是复读上一条
- [ ] 问手册没写的问题 → 提示「手册暂未覆盖」+ 缺口，不编答案
- [ ] 变更知识库后跑 `node tools/eval_qa.js <sys> [问题文件] [--role=xxx]`，命中率不低于上次基线
- [ ] 切换角色后会话重置，回答范围跟着角色变
- [ ] 浏览 ↔ 问答切换后地址栏带/去掉 `mode=qa`，刷新仍停在当前模式

- [ ] 根 `README.md` 的目录结构里已加上该系统
