## 说明

- 手册只有一个版本，没有按角色拆册，所以 `kb.json` 里只定义了一个角色
  `staff`（住房保障管理），页面上不显示角色切换，直接按章节模块导航。
- 手册里提到初审 / 复审角色（我的待办、公租房复审），但没有单独的章节体系，
  统一放在「准入登记」「配后管理」模块下，权限划分写进了缺口清单。
- 手册里没写的内容（申请条件、材料清单、审批时限、租金标准、换房流程等）
  已整理进 `gaps`，检索不到时页面会明确提示“手册暂未覆盖”。
