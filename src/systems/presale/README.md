## 说明

- 主管部门侧重三级审核（监管账户 / 监管协议 / 政策优惠 / 资金支用 / 退房退款）和节点降低的二级审核；
  开发企业侧重工程合同、监管账户与协议申请、入账、支用、核销、退房退款。
- 手册里反复出现的三级审核链路已按“经办人员初审 → 科室负责人复审 → 分管领导终审”统一表述。
- 手册未写的内容（审核时限、监管比例标准、支用额度规则、保函业务、入账划分规则等）都在 `gaps` 里，
  检索不到时页面会明确提示“手册暂未覆盖”。
