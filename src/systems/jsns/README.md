## 说明

- 三个角色差异明显：主管单位做审批（企业备案、项目备案、预售/现售许可、合同备案、撤销合同）；
  开发企业做申报（单位信息、宗地、项目运行、测绘委托、面积挂接、合同网签）；
  测绘机构只做委托受理和成果备案。
- 主管单位版手册 2.3 节把四类“无独立菜单”的备案业务讲得较细，已单独拆成答题，并保留“退回发起人”等关键口径。
- 主管单位版手册里带“【截图占位：…】”字样的段落没有配图（手册原文如此），对应条目 `shots` 为空。
- 手册未写的政策口径（预售条件、收费、公示期、数据包格式、权限划分等）都在 `gaps` 里。
